# 음악 감상 수행평가 퀴즈

GitHub Pages에서 바로 실행할 수 있는 정적 웹사이트입니다.

## 기능
- 음악 파일 업로드
- 곡명 / 작곡가 / 시대 / 연주형태 저장
- IndexedDB에 음원과 정보를 저장하므로 새로고침 후에도 유지
- 등록한 곡을 한 사이클씩 랜덤 출제
- 각 곡마다 4개 항목 중 하나를 랜덤으로 질문
- 최대 7지선다
- 음악 재생 버튼을 여러 번 눌러 반복 청취 가능
- 정답/오답 즉시 표시
- 한 사이클 종료 후 점수와 정답률 표시

## GitHub Pages 사용법
1. GitHub에서 새 repository를 만듭니다.
2. `index.html`, `style.css`, `app.js` 세 파일을 업로드합니다.
3. Repository의 Settings → Pages에서 Deploy from a branch를 선택합니다.
4. `main` 브랜치의 `/ (root)`를 선택하고 저장합니다.
5. 생성된 GitHub Pages 주소로 접속합니다.

## 중요한 점
이 사이트의 곡 데이터는 서버나 GitHub에 업로드되는 것이 아니라 **사용 중인 브라우저의 IndexedDB에 저장**됩니다.
따라서 다른 컴퓨터나 휴대폰에서 같은 데이터를 자동으로 공유하지는 않습니다.
